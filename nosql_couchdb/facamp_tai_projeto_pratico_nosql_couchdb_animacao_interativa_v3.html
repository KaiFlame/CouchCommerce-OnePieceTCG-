Projeto prático NoSQL: e-commerce com Apache CouchDB

Projeto completo, do problema ao deploy, com banco NoSQL de documentos open source, Python/Flask, REST/JSON, modelagem documental, índices Mango, controle de revisões, testes e atividade prática.

NoSQLCouchDBPython/FlaskREST/JSON
Objetivo: compreender o ciclo completo de uma aplicação com banco documental.
Aplicação prática NoSQL

Projeto: CouchCommerce FACAMP

Desenvolvimento de uma aplicação prática de e-commerce para resolver o problema de organização, consulta e atualização de catálogo, clientes e pedidos utilizando um banco NoSQL orientado a documentos.

Problema que será tratado

Pequenas operações de comércio eletrônico precisam disponibilizar catálogos flexíveis, registrar clientes e pedidos, atualizar estoque e preservar o histórico das compras, mesmo quando a estrutura dos dados pode evoluir rapidamente.

Solução proposta

Construir um MVP de e-commerce com Python + Flask e Apache CouchDB, armazenando os dados em documentos JSON e utilizando API REST, consultas Mango, índices, controle de revisões e replicação.

Objetivo de negócio

Permitir consulta de produtos, cadastro de clientes, carrinho, checkout e histórico de pedidos.

Objetivo técnico

Aplicar modelagem documental, embed x reference, REST/JSON, índices Mango, _id e _rev.

Objetivo didático

Comparar na prática o ciclo de desenvolvimento de uma aplicação NoSQL com o projeto relacional.

Problemacatálogo e pedidos precisam de flexibilidade e histórico
→
AplicaçãoFlask implementa as regras e a experiência do usuário
→
Banco NoSQLCouchDB persiste documentos JSON e controla revisões
→
ResultadoMVP funcional, testável e preparado para deploy
Questão norteadora: como projetar uma aplicação de e-commerce em que os dados sejam organizados em documentos, mantendo desempenho, rastreabilidade e consistência suficientes para o fluxo de compra?

32. Wrapper HTTP

def couch(method,path="",**kwargs):
    response=requests.request(method,f"{DB_URL}{path}",timeout=10,**kwargs)
    if response.status_code>=400: raise RuntimeError(response.text)
    return response.json()
